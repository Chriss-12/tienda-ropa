# Frontend design
Ground each page in its subject, users, and purpose. Before coding, define a concise visual system: named colors, typography roles, spacing/layout, and one memorable visual idea. Avoid defaults that could be reused unchanged for any product. Choose a meaningful hero, deliberate typography, and clear hierarchy. Do not use identical cards, decorative gradients, labels, or motion by default. Use motion sparingly and respect reduced motion. Make interfaces responsive, keyboard accessible, and visually checked when preview is available. Write plain, actionable interface copy.
