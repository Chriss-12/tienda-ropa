# Web design review
Review relevant files and report actionable findings with file/line references. Check narrow, medium, and wide layouts for clipping; semantic landmarks and heading order; labels and image alternatives; keyboard access and visible focus; touch targets; contrast; interaction feedback and validation; loading, empty, error, and success states; reduced motion; and consistent spacing/hierarchy. Do not claim tests that were not performed. See upstream source for the full guideline set.
