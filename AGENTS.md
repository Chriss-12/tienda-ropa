# Project instructions

## Stack
- Use React 19, TypeScript, Vite, and pnpm as configured in this project. Follow existing patterns before adding dependencies.
- Design mobile-first; support keyboard and touch, visible focus, readable contrast, and reduced motion.
- Include useful loading, empty, error, success, and form validation states. Controls must perform the action their labels promise.

## Design
- Ground each interface in its audience, content, and purpose. Before substantial UI work, define a compact palette, typography, spacing/layout, and one distinctive visual idea.
- Avoid generic repeated cards, gradients, eyebrow labels, and decorative motion unless they serve this product.
- Use concise, natural copy with concrete labels and active voice.

## React and TypeScript
- Keep components focused and composable. Prefer explicit variants and composition over many boolean props.
- Avoid unnecessary state, effects, memoization, re-renders, and request waterfalls. Keep bundles lean.
- Follow the installed React version and project architecture.
